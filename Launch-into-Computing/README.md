# Module 1 — Launch into Computing  
### MSc Artificial Intelligence — University of Essex Online  


---

## Overview

Module 1 introduces the core foundations of computing and prepares me for the technical demands of the MSc Artificial Intelligence programme. It focuses on essential concepts such as algorithms, programming principles, data structures, problem‑solving, and computational thinking. The module builds confidence in working with code, understanding how computers process information, and applying structured approaches to technical tasks.

This module acts as the technical starting point for the rest of the MSc, ensuring I have a solid grounding before progressing into more advanced AI‑focused modules such as Machine Learning, Intelligent Agents, and Numerical Analysis.

---

## Key Topics Covered

- Fundamental programming concepts  
- Algorithmic thinking and structured problem‑solving  
- Data types, variables, and control flow  
- Functions, modularity, and code organisation  
- Basic data structures (lists, arrays, dictionaries)  
- Introduction to software development tools  
- Debugging and improving code quality  
- Understanding how computers execute instructions  

---

## Learning Outcomes

By the end of this module, I will be able to:

- Write simple programs using core programming constructs  
- Apply algorithmic thinking to solve structured problems  
- Understand how data is stored, manipulated, and processed  
- Use development tools to create, test, and debug code  
- Explain key computing concepts relevant to artificial intelligence  
- Approach more complex computational tasks with confidence  

---

## Skills Developed

- Logical reasoning and problem‑solving  
- Python programming fundamentals  
- Understanding algorithm behaviour  
- Working with basic data structures  
- Debugging and code improvement  
- Applying structured approaches to technical challenges  

---

## My Focus in This Module

This module strengthens my understanding of how algorithms work, how code is structured, and how computational logic supports artificial intelligence systems. It also ensures I am comfortable using Python, which is the primary language used throughout the MSc AI programme.
